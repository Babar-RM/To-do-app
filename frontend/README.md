# 🎨 TaskFlow Frontend Client

Modern single-page application built with **React 19**, **Vite 8**, **React Router 7**, and a bespoke **Vanilla CSS design system**.

## 🌟 Highlights
- **Adaptive Theme**: One-click Dark / Light mode toggle with system preference detection & localStorage persistence.
- **Glassmorphic UI**: Ambient blurred panels, glowing accent borders, and fluid CSS transitions.
- **Micro-Animations & Celebrations**: Confetti celebrations on task completion via `canvas-confetti`.
- **Subtask Checklists**: Fractional completion indicators and collapsible checklist items.
- **Productivity Dashboard**: Dynamic progress bar, completion rate, overdue warnings, and motivational messages.
- **Centralized Toasts**: Floating notification toasts replacing intrusive native alert dialogs.

## 🚀 Running Locally
```bash
# Install dependencies
npm install

# Start Vite development server
npm run dev

# Build for production
npm run build
```
